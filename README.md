# ILC - International Legal Center

![ILC Logo](img/logo_horizontal_white.png)

A single-page landing website for International Legal Center - the first digital international legal center.

## 🚀 About Project

Modern landing page presenting legal services and partnership program of ILC. The website offers 24/7 legal support through digital technologies.

## ✨ Features

- **24/7 Legal Support** - round-the-clock lawyer assistance
- **Partnership Program** - earning opportunities through referrals
- **Multi-format** - support for businesses, startups, and private clients
- **Professional Design** - clean and corporate appearance

## 🛠 Technologies Used

- **HTML5** - semantic markup
- **CSS3** - Flexbox, Grid, CSS Variables
- **jQuery** - interactivity and DOM manipulation
- **Google Fonts** - Montserrat font family
